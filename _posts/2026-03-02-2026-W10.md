### New Packages

<!-- <p class="added-hostname"><a href="https://rweekly.org/live" target="_blank" class="externalLink">📦 <i>Go Live for More New Pkgs</i> 📦</a></p> --> 
<p class="added-hostname"><a href="https://dirk.eddelbuettel.com/cranberries/cran/new/" target="_blank" class="externalLink">📦 <i>Keep up to date wtih CRANberries</i> 📦</a></p>


**CRAN**
+ [{sasquatch} 0.1.3](https://cran.r-project.org/package=sasquatch): Use 'SAS', R, and 'quarto' Together - A unique bridge for multilingual Quarto documents that allows users to run SAS code blocks interactively and pass data between R and SAS via 'SASPy' and 'reticulate'.
+ [{sqlfluffr} 0.1.0](https://cran.r-project.org/package=sqlfluffr): Wrapper to the 'SQL' Linter and Formatter 'sqlfluff' - Provides an R interface to the popular Python 'sqlfluff' linter; particularly interesting for your workflow as it includes special handling for 'glue' SQL syntax.
+ [{hypertext} 1.0.0](https://cran.r-project.org/package=hypertext): 'HTML' Element Construction - A framework-agnostic Domain-Specific Language (DSL) for building HTML nodes directly in R and rendering them to strings, useful for custom web reporting.
+ [{tidyaudit} 0.1.0](https://cran.r-project.org/package=tidyaudit): Pipeline Audit Trails for 'tidyverse' Workflows - Captures metadata snapshots at each step of a tidyverse pipeline to build structured audit reports without storing the actual data.
+ [{nhanesdata} 0.2.1](https://cran.r-project.org/package=nhanesdata): Harmonized Access to NHANES Survey Data - Provides instant access to over 20 years of harmonized health survey data, handling complex cycle management and type reconciliation automatically.
+ [{ggvariant} 0.1.0](https://cran.r-project.org/package=ggvariant): Tidy Visualization for Genomic Variants - A native ggplot2 toolkit that simplifies creating publication-ready lollipop plots and mutational spectrum charts from VCF files.
+ [{astronomyengine} 0.1.0](https://cran.r-project.org/package=astronomyengine): R Bindings to the 'Astronomy Engine' C Library - High-precision calculations for positions of the Sun, Moon, and planets, as well as predictions for eclipses and transits based on the VSOP87 model.
+ [{typstable} 0.1.0](https://cran.r-project.org/package=typstable): Better 'Typst' Tables - For those moving toward Typst for document rendering, this provides a pipe-friendly interface to create styled Typst table markup from R data frames.
+ [{VectorForgeML} 0.1.0](https://cran.r-project.org/package=VectorForgeML): Machine Learning with C++ Acceleration - A high-performance ML framework that uses Rcpp for vectorized model training, aimed at speed-critical statistical learning.
+ [{sessioncheck} 0.1](https://cran.r-project.org/package=sessioncheck): Checks Session Status - A utility for developers to ensure a clean R environment by throwing errors if unwanted variables exist or specific packages are loaded.
+ [{nnetLM} 1.0.1](https://cran.r-project.org/package=nnetLM): Neural Network with Levenberg-Marquardt Optimization - Implements neural networks specifically optimized for small datasets using the 'minpack.lm' engine.
+ [{obm} 2.0](https://cran.r-project.org/package=obm): Interface to 'OpenBioMaps' Data - Connects R to the OpenBioMaps open-source biodiversity platform, allowing conservationists to pull data directly into their analysis environment.
+ [{ggvegan} 0.2.1](https://cran.r-project.org/package=ggvegan): 'ggplot2' Plots for the 'vegan' Package
+ [{neuromapr} 0.2.1](https://cran.r-project.org/package=neuromapr): Spatial Null Models and Transforms for Brain Map Comparison

### Updated Packages

<i>🔍 [Search on R-universe](https://r-universe.dev/search/) 🔍</i>

+ [{xts} 0.14.2](https://cran.r-project.org/package=xts): eXtensible Time Series - A foundational package for handling time series data in R, offering a uniform interface for many different classes.
+ [{mlr3} 1.5.0](https://cran.r-project.org/package=mlr3): Machine Learning in R - The "next generation" framework for machine learning, providing a modern, object-oriented approach to building and evaluating models.
+ [{DBI} 1.3.0](https://cran.r-project.org/package=DBI): R Database Interface - The essential database interface that defines a common set of functions for interacting with various database management systems.
+ [{duckplyr} 1.2.0](https://cran.r-project.org/package=duckplyr): A 'DuckDB'-Backed Version of 'dplyr' - Combines the familiar syntax of `dplyr` with the high-performance analytical capabilities of the DuckDB engine.
+ [{ggrepel} 0.9.7](https://cran.r-project.org/package=ggrepel): Automatically Position Non-Overlapping Text Labels - A must-have extension for `ggplot2` that prevents overlapping text labels in plots.
+ [{countrycode} 1.7.0](https://cran.r-project.org/package=countrycode): Convert Country Names and Country Codes - An incredibly useful utility for harmonizing geographic data from various sources and formats.
+ [{localLLM} 1.2.1](https://cran.r-project.org/package=localLLM): Running Local LLMs with 'llama.cpp' Backend - A unique bridge allowing R users to interface with local Large Language Models directly.
+ [{survminer} 0.5.2](https://cran.r-project.org/package=survminer): Drawing Survival Curves using 'ggplot2' - The standard for creating publication-quality survival analysis visualizations (Kaplan-Meier curves).
+ [{dm} 1.1.0](https://cran.r-project.org/package=dm): Relational Data Models - Tools for working with relational data models, including visualizing schemas and handling foreign key constraints within R.
+ [{fcuk} 0.2.0](https://cran.r-project.org/package=fcuk): The Ultimate Helper for Clumsy Fingers - A unique "quality of life" package that suggests corrections when you mistype a function name in the console.
+ [{scholar} 0.2.6](https://cran.r-project.org/package=scholar): Analyse Citation Data from Google Scholar - A specialized tool for scraping and analyzing academic citation profiles and trends.
+ [{tidyseurat} 0.8.10](https://cran.r-project.org/package=tidyseurat): Brings Seurat to the Tidyverse - Essential for bioinformatics workflows, allowing users to use `tidyverse` verbs on Seurat objects (single-cell RNA-seq data).
+ [{fio} 1.0.0](https://cran.r-project.org/package=fio): Friendly Input-Output Analysis - [diffify](https://diffify.com/R/fio)
